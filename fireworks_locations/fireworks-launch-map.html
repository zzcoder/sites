Map Notes

  • Red marker: Lincoln Memorial Reflecting Pool launch site.
  • Gold marker: West Potomac Park land launch site.
  • Blue numbered markers: approximate locations for the eight Potomac River barges.
  • The official public source lists the barge launch count but does not publish individual barge coordinates, so the barge markers are planning approximations.
  • Use this map for orientation only; closures, security zones, crowds, and river restrictions can change viewing access.
