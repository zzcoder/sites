East Washington Monument Grounds

Photo Lens Guide

Simulated full-frame-equivalent views from the best photo location, approx. 38.88950, -77.03150, looking west so fireworks appear behind the Washington Monument.

Start at 35mm. Use 28mm if you want a safer frame with more sky. Use 50-70mm for a tighter monument image. Use 200mm only for abstract detail shots.

Field Notes

  • Use manual focus on the monument before it gets fully dark.
  • Start around ISO 100-200, f/8, and 2-4 seconds on a tripod; adjust after the first bursts.
  • Leave extra room above the monument because high bursts are unpredictable.
  • The moon is not shown. For the July 4, 2026 evening fireworks window, the moon is below the horizon and to the east, outside this west-facing frame.
